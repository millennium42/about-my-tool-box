# Segurança

Não abra uma issue pública para credenciais expostas, vulnerabilidades ou instruções
que possam causar acesso indevido. Envie um relatório privado pelo mecanismo de
segurança do GitHub ou contate o mantenedor antes de publicar detalhes.

Este repositório é documentação e scripts auxiliares. Um link para uma ferramenta
externa não representa endosso de segurança, disponibilidade, licença ou adequação.
Revise permissões, código, termos e dados enviados antes de instalar qualquer
integração.
