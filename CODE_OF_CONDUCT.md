# Código de conduta

Este projeto busca uma colaboração técnica, respeitosa e acessível.

Não são aceitos assédio, discriminação, exposição de dados privados, ataques
pessoais ou contribuição deliberadamente enganosa. Mantenha críticas focadas no
problema, explique evidências e ajude a corrigir o que estiver incompleto.

Para situações sensíveis, use o canal privado descrito em [SECURITY.md](SECURITY.md).
