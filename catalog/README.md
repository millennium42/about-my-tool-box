# Catálogo

O catálogo responde quatro perguntas antes de uma ferramenta entrar em um projeto:

1. Qual problema concreto ela resolve?
2. Qual é a fonte oficial exata?
3. Que evidência existe neste repositório ou no projeto?
4. Qual é o custo, a licença e a alternativa open source quando aplicável?

Arquivos canônicos:

- [tools.md](tools.md): ferramentas executáveis e bibliotecas com fonte exata;
- [stacks.md](stacks.md): decisões mínimas por tipo de projeto;
- [paid-services.md](paid-services.md): serviços pagos ou híbridos e alternativas
  open source públicas no Git;
- [mcp-servers.md](mcp-servers.md): protocolo, SDKs e servidores MCP;
- [evidence/](evidence/): o que foi realmente executado;
- [retired.md](retired.md): nomes ambíguos, fontes antigas e itens arquivados;
- [tool-entry-template.md](tool-entry-template.md): contrato para novas entradas.

**Verificada/E3** é a única indicação de uso padrão. **Em avaliação/E1–E2** exige
validação no projeto; **Referência** não é uma dependência. Uma entrada retirada não
deve reaparecer sem fonte, licença, necessidade e evidência novas.
