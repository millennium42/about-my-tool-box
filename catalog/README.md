# Catálogo

O catálogo distingue recomendação de referência. A tabela completa está em
[tools.md](tools.md); integrações MCP estão em [mcp-servers.md](mcp-servers.md) e
perfis de escolha em [stacks.md](stacks.md).

Não instale uma entrada somente porque ela aparece na tabela. **Verificada** é a
única indicação de uso padrão; **Em avaliação** exige validação no projeto; e
**Referência** serve para comparação.

Use [tool-entry-template.md](tool-entry-template.md) para novas entradas.
