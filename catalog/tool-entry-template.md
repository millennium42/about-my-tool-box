# Modelo de entrada de ferramenta

Copie esta estrutura para documentar uma ferramenta candidata:

```markdown
## Nome

- **Status**: Em avaliação
- **Tipo**: CLI, biblioteca, MCP, skill, SaaS ou serviço
- **Categoria**: ...
- **Fonte oficial**: ...
- **Licença/custo**: ...
- **Compatibilidade**: Windows, WSL2, Linux, macOS
- **Pré-requisitos**: ...
- **Instalação**: comando reproduzível
- **Uso mínimo**: comando ou prompt reproduzível
- **Verificação**: resultado esperado e resultado observado
- **Riscos/limites**: permissões, dados, rede, custo e manutenção
- **Última validação**: AAAA-MM-DD, ambiente e versão
```

Só altere o status para **Verificada** quando a evidência for E3 conforme
[guides/verification.md](../guides/verification.md).
