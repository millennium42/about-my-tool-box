# Playbook: pronto para produção ou demonstração

Use a expressão somente quando o escopo estiver definido.

## Produção

- [ ] código e configuração funcionais;
- [ ] testes, build, smoke e healthcheck executados;
- [ ] CI remoto verde no commit atual;
- [ ] migrações, rollback ou limitação documentados;
- [ ] autenticação, autorização, logs, secrets e backups revisados;
- [ ] observabilidade e plano de falha definidos;
- [ ] documentação de operação atualizada.

## Demonstração

- [ ] fluxo reproduzível do zero;
- [ ] dados de demonstração claramente identificados;
- [ ] prints ou evidência visual atuais;
- [ ] relatório e slides, quando fizerem parte do objetivo;
- [ ] limitações visíveis para não vender protótipo como produto.

Um bloco técnico pode estar fechado sem que o produto inteiro esteja pronto.
