# Instruções para agentes

Este repositório é uma base pública de referência. Antes de agir:

1. leia `README.md`;
2. leia o guia e o perfil aplicáveis;
3. trate somente entradas **Verificada** como recomendação padrão;
4. produza uma spec antes de construir uma feature;
5. declare o que foi provado, inferido, bloqueado ou deixado pendente;
6. não publique segredos, PII, caminhos pessoais ou dados de projetos privados.

## Forma de trabalhar

- faça uma tarefa focal por vez;
- mantenha mudanças pequenas e revisáveis;
- execute a verificação antes de declarar conclusão;
- atualize documentação e evidência junto com a mudança;
- não faça ações destrutivas sem autorização explícita;
- confirme o estado atual do projeto antes de confiar em handoffs ou documentos antigos.

As instruções específicas do projeto em que o agente está trabalhando têm prioridade
para decisões locais. Esta base fornece princípios e opções, não substitui os
requisitos do projeto.
