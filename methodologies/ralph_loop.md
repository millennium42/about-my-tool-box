# Loop de entrega

Um ciclo simples para reduzir escopo difuso e manter o trabalho verificável.

## Spec

Entenda objetivo, requisitos indispensáveis, restrições, fora de escopo e definição
de concluído. Salve em `specs/<nome>.md` usando o template do repositório.

## Build

Implemente apenas o que a spec pede. Faça uma unidade pequena por vez e mantenha a
verificação próxima da mudança.

## Review

Compare o resultado com cada requisito. Liste lacunas, riscos e o que foi realmente
executado. Não transforme inferência em prova.

## Learn

Se surgir um procedimento repetível, transforme-o em playbook ou skill genérico.
Não copie detalhes de um projeto privado para esta base pública.

Essas são fases da metodologia, não comandos automaticamente instalados por este
repositório.
