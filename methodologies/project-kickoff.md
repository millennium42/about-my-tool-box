# Kickoff de projeto

Este arquivo é um atalho para o roteiro completo em
[guides/first-project.md](../guides/first-project.md).

O kickoff deve produzir, nesta ordem:

1. contexto do problema e usuário;
2. spec com requisitos verificáveis;
3. perfil mínimo de stack;
4. ambiente reproduzível;
5. primeira verificação executada;
6. registro de decisões e fora de escopo.
