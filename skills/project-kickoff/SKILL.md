# Kickoff de projeto

Use quando o projeto for novo, quando o contexto estiver incompleto ou quando uma
feature ainda não tiver critérios de aceite.

## Procedimento

1. Pergunte ou descubra objetivo, usuários, restrições e resultado esperado.
2. Registre requisitos indispensáveis e fora de escopo.
3. Crie uma spec com critérios observáveis antes do código.
4. Escolha o perfil mínimo de stack e justifique exceções.
5. Registre ambiente, versões, segredos necessários e comandos de verificação.
6. Execute uma verificação inicial e entregue o estado real.

Não instale ferramentas apenas porque estão listadas no catálogo. Use o status e a
evidência registrados no projeto.
