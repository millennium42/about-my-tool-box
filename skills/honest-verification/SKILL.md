# Verificação honesta

Use para afirmações de funcionamento, compatibilidade, segurança, preço, licença,
disponibilidade ou prontidão.

1. Transforme a afirmação em teste ou fonte adequada.
2. Registre versão, ambiente, data e escopo.
3. Execute o teste ou declare o bloqueio.
4. Preserve somente a saída essencial sanitizada.
5. Classifique como provado, inferido, não verificado ou bloqueado.
6. Rebaixe a conclusão se a evidência não cobrir a integração inteira.
7. Para preço/licença, consulte fonte atual; para serviço pago, compare alternativa
   OSS pública e declare diferenças.

Estrelas, marketing, mocks e código não executado não são prova. E3 exige execução
reproduzível; documentação sozinha sustenta no máximo E1/E2.
