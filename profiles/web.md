# Perfil: web full-stack

## Kit mínimo

- Git;
- Node.js e npm **ou** Python, conforme o framework escolhido;
- PostgreSQL;
- testes do framework;
- Docker Compose se o ambiente local precisar de serviços.

## Escolha rápida

- interface e API integradas: TypeScript/Node ou Laravel;
- painel administrativo: Laravel + Filament/Livewire;
- aplicação pequena: framework nativo ou biblioteca mínima;
- autenticação: mecanismo mantido pelo framework ou provedor explicitamente escolhido.

## Verificação mínima

Subir a aplicação localmente, executar uma rota de saúde, rodar o teste principal,
verificar migração em banco descartável e confirmar que nenhum segredo foi commitado.
