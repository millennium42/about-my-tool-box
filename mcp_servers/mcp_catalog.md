# Catálogo de MCP

O catálogo canônico está em [catalog/mcp-servers.md](../catalog/mcp-servers.md).

MCP é um protocolo; a existência do protocolo não significa que um servidor esteja
instalado, disponível ou autorizado no cliente de IA. Registre cada servidor com o
[template](mcp-server-template.md) e só marque como verificado após um teste e2e.
